Programme overview

Three Months Of Real Memory Training

The Super Memory Programme is AMA's regular core programme — the programme the academy is built around. Over three months, students spend structured time learning and practising a wide range of Super Memory Programme techniques.

This goes far beyond a simple introduction. Students participate in practical activities involving memory, concentration, learning techniques, blindfold-related training and progressive recognition activities.

Every technique is taught through experience. Students watch live demonstrations, try the methods themselves, understand how each technique works, and build confidence through repeated practice.
