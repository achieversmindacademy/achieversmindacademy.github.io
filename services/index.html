Learning designed to build stronger minds.

01 FREE SCHOOL PROGRAMME

Basic SMP

Free Super Memory Programme for Tamil Schools

Basic SMP is an introductory Super Memory Programme offered free of charge to Tamil schools. It introduces students to foundational memory and concentration practices through a simple, engaging school-based experience.

Key Highlights

  • Free programme for Tamil schools
  • Introduction to memory and concentration
  • SMP Yoga
  • 10 Habits to Improve and Protect Your Brain
  • School-based programme

For: Tamil school students

02 CORE PROGRAMME

Super Memory Programme

Our core 3-month memory development programme.

The Super Memory Programme is AMA's regular 3-month programme designed for students who want to develop memory, concentration and learning abilities through structured training.

Key Highlights

  • 3-month programme
  • Levels 1–3
  • Memory training
  • Blindfold recognition
  • SMP Yoga
  • Kasi Blantca
  • SALA Technique
  • Creative Text
  • Practical training

For: Students seeking structured memory development

03 PREMIUM PROGRAMME

Memory Mastery Certification Programme

Take memory training further.

The Memory Mastery Certification Programme is an intensive long-term programme designed for students who want to go deeper into the Super Memory Programme and develop their memory and learning skills through sustained training.

Key Highlights

  • 6 months duration
  • Saturday & Sunday sessions
  • Training materials included
  • Accommodation & facilities
  • Healthy natural food
  • Lectures & activities
  • 100% money-back guarantee
